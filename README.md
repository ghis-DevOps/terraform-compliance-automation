An enterprise-grade, modular Terraform framework designed to automate cloud compliance guardrails, enforce policy checks within CI/CD pipelines, and integrate with external corporate compliance platforms using Python and Bash.

The repository is structured into two main layers:
1. **Bootstrap Layer (`bootstrap/`):** Sets up the underlying state storage (KMS-encrypted S3 bucket, DynamoDB lock table) and passwordless authentication (GitHub Actions OIDC provider and IAM execution role).
2. **Landing Zone / Compliance Automation (`/`):** Manages cloud guardrails (AWS Config rules), static security checks, external Python compliance telemetry, and automated GitHub Actions delivery.
